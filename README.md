# Mars Rover
## Басова Татьяна Валентиновна, М8О-412Б-22
Планетоход-разведчик собирает образцы почвы и отвозит на базу.
1) Планетоход ездит по полю и собирает подсвеченные образцы почвы. Как только переполнен, должен вернуться на базу, чтобы сдать образцы.
2) На поле есть зоны радиационной пыли, заезжая в которые, планетоход погибает. Планетоход может активировать временный щит, чтобы проехать через такую зону.
